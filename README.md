# python-learning

Учебные проекты по Python: от основ до работы с API нейросетей.

## Что внутри
- `lesson_*.py` — учебные проеты на Python
- `expenses_app/` — проект «Журнал расходов»: классы, модули, тесты pytest

## Как запустить
1. Создать окружение: `python -m venv venv`
2. Активировать (Windows PowerShell): `.\venv\Scripts\Activate.ps1`
3. Установить библиотеки: `pip install -r requirements.txt`
4. Запустить проект: `cd expenses_app`, затем `python main.py`

## Тесты
`cd expenses_app`, затем `pytest`
